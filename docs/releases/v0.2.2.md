# KLEANFW 0.2.2

Apps release of KLEANFW, a custom firmware for the **Quansheng
UV-K1 / UV-K5 V3 (PY32F071 + BK4829 only)**. It is a modified version of
[GOGUFW 3.6.2](https://github.com/Gogu-Qs/GOGUFW-UV-K1-Messenger) by Gogu-Qs
(F4HWN 6.3.0 base) and an independent project, not affiliated with or
endorsed by Gogu-Qs, F4HWN or Quansheng.

0.2.2 adds QR Map, updates the apps to the latest F4HWN source, keeps one
call tone and stops VOX from transmitting inside the menu.

> **This replaces the v0.2.2 withdrawn on 2026-11-21.** It does not contain
> that build's TX power changes. If you installed it, flash this one.

## Highlights

- **QR Map (new).** Shows a received position as a QR code that a phone opens
  on a map (Google, Apple, `geo:`, OpenStreetMap or plain text). Open it from
  APRS RX or EPIRB 406 with **7**, then **MENU**. Opening it from APRS RX ends
  the app: its received frames are lost and nothing is received until EXIT
  brings it back. Compressed APRS positions are not supported.
- **Apps updated.** The 22 apps shared with F4HWN now follow its latest source
  (main `11035b83`, after v7.0.0), keeping the shared APRS profile with
  frequency and power, private tuning and FM VFO/Memory.
- **Beacon** opens in `READY` and only transmits after **MENU**. It also gains
  its own TX power and an A1A mode.
- **APRS comment.** The default `Comm.` is now empty. A comment already saved on
  the radio is kept until APRS TX is reinstalled.
- **VOX** no longer transmits while the menu is open. It resumes about 0.8 s
  after leaving the menu, and PTT still works inside it.
- **CALLTX** keeps TONE1 as its only call melody. The `CllTon` menu and CHIRP
  setting are gone; `CllVol` stays.
- **Version labels.** Apps whose code differs from the official F4HWN build use
  a `-klean` suffix. The radio's app list shows only the first four characters.

**Left out** because this firmware cannot support them: EPIRB 406 homing keys
8 and 9, the SSTV picture saved across launches, and the live GPS position in
APRS TX.

## Before you flash

- Back up the radio and its calibration with CHIRP and keep a DFU recovery
  image.
- First boot after updating: the version reset clears KEY_LOCK, MENU_LOCK,
  SET_KEY and SET_INV and turns `SetRxG` back ON.
- Use only the KLEANFW 0.2.2 CHIRP module (model **UV-K1 / UV-K5 V3 KLEANFW**).
  The EEPROM layout is the same as 0.2.1.
- **APRS apps:** write down your APRS profile first, because reinstalling
  APRS TX restores its factory profile. Install `APRSTX.app` first, then
  `APRSEdit.app`, both from `Apps.zip`. The official F4HWN APRS TX has no
  frequency field and does not work with this APRS Edit.
- GitHub does not accept `.app` attachments, so the apps come zipped. Install
  them with UV Studio (Apps page).

## Checks on a radio

The VOX fix is radio-tested. The app update and QR Map were checked with builds
and host tests where the app has them, and are **not radio-tested yet**. Beacon,
FoxHunt, Spectrum3D and the games have no host tests. Useful checks, with
reports in [GitHub Issues](https://github.com/AislanJefferson/KLEANFW/issues):

1. APRS Edit opens and shows `Freq` and `Power`. APRS RX follows that frequency.
2. APRS RX on a Mic-E frame and on a standard position frame: **7**, **MENU**,
   scan the code with a phone, then EXIT back to APRS RX.
3. APRS RX with QR Map not installed: `NO QR Map` appears and reception goes on.
4. Beacon at low power into a dummy load, in F2A and A1A, before any use on the
   air. Then APRS TX, SSTV TX, APRS DIGI and KISS TNC.
5. EPIRB 406: a decoded position opens in QR Map.
6. FM VFO and FM Memory open, tune and leave without the closing key acting on
   the main screen.
7. SystemInfo: minimum free stack after an APRS RX session with long frames.
