# KLEANFW 0.2.2

TX power fix release of KLEANFW, a custom firmware for the **Quansheng
UV-K1 / UV-K5 V3 (PY32F071 + BK4829 only)**. It is a modified version of
[GOGUFW 3.6.2](https://github.com/Gogu-Qs/GOGUFW-UV-K1-Messenger) by Gogu-Qs
(F4HWN 6.3.0 base) and an independent project, not affiliated with or
endorsed by Gogu-Qs, F4HWN or Quansheng.

0.2.2 fixes two errors in how the TX power bias is computed. Everything else
is the same as 0.2.1.

> **Not radio-tested yet.** The fixes were checked by code review, a host
> test against the stock formula and builds. HOP works between 0.2.0, 0.2.1
> and 0.2.2 radios.

## Highlights

- **HIGH no longer wraps around.** HIGH adds 24 to the calibration bias in
  one byte, so a calibration value of 232 or more wrapped to a very low
  bias (an erased calibration, 0xFF, gave 23 out of 255). The sum now stops
  at 255.
- **Lower half of each calibration band.** Below the middle of a band (for
  example 144–148 MHz and 400–435 MHz), the bias was interpolated from the
  Mid value instead of the Low one. It was off by their difference and could
  wrap around near the band middle. It is now interpolated like the stock K1
  firmware 7.03.05. Bands whose Low and Mid values are equal are unchanged.

TX power can change on radios whose calibration falls in these cases. The
HIGH offset (+24) and the drive gain are the same as in 0.2.1.

## Before you flash

- Back up the radio and its calibration with CHIRP and keep a DFU recovery
  image.
- First boot after updating: the version reset clears KEY_LOCK, MENU_LOCK,
  SET_KEY and SET_INV and turns `SetRxG` back ON.
- Use only the KLEANFW 0.2.2 CHIRP module (model **UV-K1 / UV-K5 V3 KLEANFW**).
  The EEPROM layout is the same as 0.2.1.
- Installed apps keep working (same app API); the apps are byte-identical to
  those of 0.2.1. To install them, unzip `FM-Search-Apps.zip` and install
  both FM apps and Search.app with UV Studio (Apps page). GitHub does not
  accept `.app` attachments, so the apps come zipped.

## Checks on a radio

Useful checks, none of which needs a wattmeter, with reports in
[GitHub Issues](https://github.com/AislanJefferson/KLEANFW/issues). Always
transmit into a suitable antenna or dummy load, on a frequency you are
allowed to use.

1. Read the values in CHIRP → Calibration → TX Power and note the bands
   where Low and Mid differ, or where a value is 232 or more.
2. Compare HIGH with the stock firmware in a multiboot slot: same frequency
   and antenna, reading the signal on a second radio.
3. In a band where Low and Mid differ (144–148 or 400–435 MHz), step across
   the band on HIGH: the signal should not drop suddenly near the band
   middle.
