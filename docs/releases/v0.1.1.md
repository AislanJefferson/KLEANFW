# KLEANFW 0.1.1

Maintenance release of KLEANFW, a custom firmware for the **Quansheng UV-K1 /
UV-K5 V3 (PY32F071 + BK4829 only)**. It is a modified version of
[GOGUFW 3.6.2](https://github.com/Gogu-Qs/GOGUFW-UV-K1-Messenger) by Gogu-Qs
(F4HWN 6.3.0 base) and an independent project, not affiliated with or
endorsed by Gogu-Qs, F4HWN or Quansheng.

**0.1.1 replaces 0.2.0**, which was published on 2026-11-14 and withdrawn the
same day. None of the 0.2.0 changes are in this release. If you flashed 0.2.0,
flash 0.1.1 and switch to the 0.1.1 CHIRP module.

## Highlights

- **Spectrum (F+5), MR mode**:
  - Sweeps the scan list of the channel on screen (`ChList`) instead of the
    active memory scan list (`ScList`), with the memory scan rules (excluded
    channels skipped, priority channels included).
  - Key 4 is local to Spectrum and cycles `ALL`, each list that has channels
    to sweep (`01`, `02`, ...), then `OFF` (every saved channel, label
    `OFF <n>`). `ScList` is no longer changed.
  - Fix: with the scan priority on (`ScPri`, `+`), the 2 priority channels
    are swept with their list. Before this fix a list made only of them swept
    nothing and key 4 only alternated `ALL` and `OFF`.
- **Smaller image, same behaviour**: the libc start files and the
  printf conversions and flags that no format uses were removed (-668 bytes).
  This change leaves the BK4829 register access and SysTick code and the
  multiboot RAM stub byte-identical.

## Before you flash

- Back up the radio and its calibration with CHIRP and keep a DFU recovery
  image.
- First boot after updating (from 0.1.0 or 0.2.0): the version reset clears
  KEY_LOCK, MENU_LOCK, SET_KEY and SET_INV and turns `SetRxG` back ON.
- Use only the KLEANFW 0.1.1 CHIRP module (model **UV-K1 / UV-K5 V3 KLEANFW**).
  The EEPROM layout is the same as 0.1.0 and 0.2.0.
- The apps are byte-identical to 0.1.0 (same app API); installed apps do not
  need to be reinstalled. To install them, unzip `FM-Search-Apps.zip` and
  install both FM apps and Search.app with UV Studio (Apps page). GitHub does
  not accept `.app` attachments, so the apps come zipped.

## Checks on a radio

The changes in this release were checked by code review and builds. Useful
checks, and reports in
[GitHub Issues](https://github.com/AislanJefferson/KLEANFW/issues):

1. F+5 in MR mode sweeps the list of the channel on screen; key 4 cycles
   `ALL`, the lists, `OFF`, then `ALL`.
2. With `ScPri` on, a list that holds the priority channels sweeps them.
3. Messages, menus and the status bar show the same text as in 0.1.0 (the
   printf change).
