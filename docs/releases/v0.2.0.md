# KLEANFW 0.2.0

HOP release of KLEANFW, a custom firmware for the **Quansheng UV-K1 /
UV-K5 V3 (PY32F071 + BK4829 only)**. It is a modified version of
[GOGUFW 3.6.2](https://github.com/Gogu-Qs/GOGUFW-UV-K1-Messenger) by Gogu-Qs
(F4HWN 6.3.0 base) and an independent project, not affiliated with or
endorsed by Gogu-Qs, F4HWN or Quansheng.

0.2.0 makes the HOP voice scrambler work between radios: the receiver syncs
on every over and decodes the voice. It is built on 0.1.4 and has no
relation to the 0.2.0 withdrawn on 2026-11-14.

> **HOP is not compatible with 0.1.4 and earlier.** Every radio of a HOP
> group needs 0.2.0, with the same CryKey, `MsgRx` ON and `VOX` OFF. The
> fixed scrambler, the Messenger and everything else still work with older
> KLEANFW versions.

## Highlights

- **HOP decodes between radios.** The seed and resync bursts went on air
  with the TX audio mute on, so the receiver never opened a HOP session.
  They now follow the same pattern as every other tone TX in the firmware.
- **Reliable start.** The seed burst is sent at 0 s and repeated at 0.5 s,
  so a receiver that misses the first one still joins before the voice.
  Wait about 1 s after PTT before talking.
- **Resyncs are a short silence.** The burst is resent at 8 s (which
  measures the clock drift early) and then every 16 s (24 s, 40 s...). Each
  one cuts the voice for ~0.3 s; the receiver mutes its audio during it, so
  there is no whistle. A receiver that joins mid-over waits up to 16 s.
- **HOP always runs Wide.** TX and RX use the Wide filter on a HOP channel
  whatever its W/N, so both ends always match. The screen shows W, the W/N
  key gives the double beep, and the stored W/N applies again when HOP is
  turned off.
- **Carriers hop far apart.** 8 carriers over the whole 2600–3500 Hz range;
  each is used once every 4 s and the next one is at least 386 Hz away. A
  radio with a fixed scrambler near a HOP carrier no longer hears long
  stretches nearly clear.
- **Session icon.** The scrambler icon on the VFO line is drawn inverted
  while a HOP session runs on that VFO; a plain icon means HOP is set but
  not in step.

## Before you flash

- Back up the radio and its calibration with CHIRP and keep a DFU recovery
  image.
- First boot after updating: the version reset clears KEY_LOCK, MENU_LOCK,
  SET_KEY and SET_INV and turns `SetRxG` back ON.
- Use only the KLEANFW 0.2.0 CHIRP module (model **UV-K1 / UV-K5 V3 KLEANFW**).
  The EEPROM layout is the same as 0.1.4.
- Installed apps keep working (same app API). To install them, unzip
  `FM-Search-Apps.zip` and install both FM apps and Search.app with UV Studio
  (Apps page). GitHub does not accept `.app` attachments, so the apps come
  zipped.

## Checks on a radio

HOP was tested between two radios: sync on every over, voice decoded,
resyncs heard as short silences, the W/N key refusal and the W label on a
HOP channel. Reports go to
[GitHub Issues](https://github.com/AislanJefferson/KLEANFW/issues).
