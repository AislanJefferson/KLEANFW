# KLEANFW 0.2.3

Firmware and apps release of KLEANFW, a custom firmware for the **Quansheng
UV-K1 / UV-K5 V3 (PY32F071 + BK4829 only)**. It is a modified version of
[GOGUFW 3.6.2](https://github.com/Gogu-Qs/GOGUFW-UV-K1-Messenger) by Gogu-Qs
(F4HWN 6.3.0 base) and an independent project, not affiliated with or
endorsed by Gogu-Qs, F4HWN or Quansheng.

0.2.3 adds the COMPANDER RX side-key action and three sonde apps, opens QR Map
with key 7 in every app that sends positions, fixes the FM VFO/Memory apps and
updates KISS TNC to 1.1.

## Highlights

- **COMPANDER RX (new side-key action).** Turns the RX compander (expander) of
  the current channel or VFO on or off for now, without saving: the channel's
  `Compnd` setting never changes and comes back after a channel or band change,
  the `Compnd` menu or power-off. TX is unchanged. FM only; on AM/USB it
  refuses with the double beep. Also in the CHIRP key-action list.
- **Sonde M10, Sonde MRZ and Sonde RS41 (new apps)**, imported from F4HWN
  (`73fc66c7`). KLEANFW has no GeoNav, so **7** shows the decoded position as a
  QR code with QR Map. Sonde M20 is left out because it does not fit the 4 KiB
  app slot with this toolchain.
- **QR Map on key 7.** APRS RX and EPIRB 406 now open QR Map at once with
  **7**, with no MENU confirmation. Leaving APRS RX this way still clears its
  received frames.
- **FM VFO / FM Memory 3.6.2 fixes.** Auto scan stops at the band's top (on
  76-90 and 64-76 it filled the memories with repeats), Ch Save keeps a
  memory's name and no longer erases the names sector for a new station, the
  menu is modal, a half-typed frequency is dropped by any other key, and a
  memory at the very top of the band is no longer hidden.
- **FM VFO Ch Save is shorter.** MENU opens on **SAVE**, so MENU, MENU opens Ch
  Save and a third MENU stores. Ch Save offers the memory that already holds
  the frequency, else the first empty one, and shows what an occupied memory
  holds.
- **Firmware boot fix.** A saved FM Memory channel at the very top of the band
  (108.0, 90.0, 76.0) is kept at power-on instead of moving to the next memory.
- **APRS RX** saves the view (\*) and the speaker (1) again; 0.2.2 reset both
  at every launch.
- **KISS TNC 1.1** (F4HWN) passes 17-byte AX.25 U/S frames, so connected mode
  works.
- **APRS Edit:** key 1 in the comment editor also gives `-`.

## Before you flash

- Back up the radio and its calibration with CHIRP and keep a DFU recovery
  image.
- First boot after updating: the version reset clears KEY_LOCK, MENU_LOCK,
  SET_KEY and SET_INV and turns `SetRxG` back ON.
- Use only the KLEANFW 0.2.3 CHIRP module (model **UV-K1 / UV-K5 V3 KLEANFW**).
  The EEPROM layout is the same as 0.2.2; the module only adds COMPANDER RX to
  the key actions.
- Update `FMVFO.app` and `FMMemory.app` together from `FM-Search-Apps.zip`.
- **APRS apps:** reinstalling APRS TX restores its factory profile, so write
  down your APRS profile first. Install `APRSTX.app` before `APRSEdit.app`,
  both from `Apps.zip`.
- GitHub does not accept `.app` attachments, so the apps come zipped. Install
  them with UV Studio (Apps page).

## Checks on a radio

COMPANDER RX, the FM VFO/Memory changes and the boot fix are radio-tested. The
sonde apps, the QR Map key change, KISS TNC 1.1, the APRS RX save fix and the
APRS Edit key were checked with builds and host tests where the app has them,
and are **not radio-tested yet**. Useful checks, with reports in
[GitHub Issues](https://github.com/AislanJefferson/KLEANFW/issues):

1. Sonde M10, MRZ or RS41 on a real sonde: the position decodes, **7** opens QR
   Map, a phone scans the code, then EXIT goes back.
2. APRS RX and EPIRB 406: **7** opens QR Map at once.
3. APRS RX: change the view (\*) and the speaker (1), leave, open it again;
   both are kept.
4. KISS TNC: a connected-mode session (SABM/UA) with a packet program.
5. SystemInfo: minimum free stack after a long sonde or APRS RX session.
