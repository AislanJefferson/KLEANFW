# KLEANFW 0.1.3

Spectrum release of KLEANFW, a custom firmware for the **Quansheng UV-K1 /
UV-K5 V3 (PY32F071 + BK4829 only)**. It is a modified version of
[GOGUFW 3.6.2](https://github.com/Gogu-Qs/GOGUFW-UV-K1-Messenger) by Gogu-Qs
(F4HWN 6.3.0 base) and an independent project, not affiliated with or
endorsed by Gogu-Qs, F4HWN or Quansheng.

0.1.3 changes only the Spectrum (F+5): a seek to the next channel with a
signal in MR, and the end of a faint tic while listening from the graph.
Everything else is the same as 0.1.2.

## Highlights

- **MR seek with UP/DOWN.** While a channel is heard in the MR Spectrum,
  UP/DOWN skips it and tunes the next channel with a signal in the key's
  direction (UP = following channels):
  - the seek opens the first channel at or over the dotted line, and wraps
    around the list;
  - with no other signal, the channel left is heard again after one round, if
    it is still transmitting;
  - UP/DOWN is ignored while the seek is looking, so a held key goes from
    signal to signal (slower while held: the keypad adds a delay per step);
  - a seek that stops early does not change the graph scale or the automatic
    trigger;
  - before, the key restarted the sweep, which reopened the strongest
    channel: the one just left.
  VFO, and UP/DOWN without a reception, are unchanged.
- **No more tic while listening from the graph.** A faint tic every
  ~0.5–1 s while listening to a signal the Spectrum found is gone: the listen
  check no longer switches the IF filter while the listen read shows the
  carrier. A reception never closes earlier than before.

## Before you flash

- Back up the radio and its calibration with CHIRP and keep a DFU recovery
  image.
- First boot after updating: the version reset clears KEY_LOCK, MENU_LOCK,
  SET_KEY and SET_INV and turns `SetRxG` back ON.
- Use only the KLEANFW 0.1.3 CHIRP module (model **UV-K1 / UV-K5 V3 KLEANFW**).
  The EEPROM layout is the same as 0.1.2.
- Installed apps keep working (same app API). To install them, unzip
  `FM-Search-Apps.zip` and install both FM apps and Search.app with UV Studio
  (Apps page). GitHub does not accept `.app` attachments, so the apps come
  zipped.

## Checks on a radio

The tic fix was tested on a radio. The MR seek was checked by code review and
builds only. Useful checks, with reports in
[GitHub Issues](https://github.com/AislanJefferson/KLEANFW/issues):

1. MR Spectrum, listening to a channel: UP/DOWN tunes the next active channel
   in that direction, also when it is the adjacent one, and the graph scale
   and trigger line stay put.
2. A signal just over the dotted line opens when the seek reaches it.
3. With no other signal, the channel left is heard again after the seek wraps
   around.
4. Holding UP/DOWN with few active channels goes from signal to signal.
5. Lists over 128 channels seek in list order.
